# 给提供算力同学的交接说明

目标是在 π0.5 上比较 baseline 与 grounded 3D displacement 注入。项目负责人不能远程登录，所以执行记录必须可回传。

## 请按阶段执行

1. 拉取仓库后，先安装环境并运行 smoke；把 `runs/reports/environment.json`、小测试输出和错误日志回传。
2. 小规模重放时核对 RGB 图像方向、EDT 点、深度 lifting、基座/世界坐标和阶段阈值。发现异常先记录，不要修改成零向量或直接质心。
3. 使用同一份正式数据完成两组训练。不要把 baseline 的训练 checkpoint 当成空间组的预训练初始化；两组都从同一个 pi05_base 开始。
4. 同时保留配置、seed、日志和 checkpoint。两组默认 69 任务；20 任务是另外的实验，不能混报。
5. ID 可先测试策略接口；完整 OOD 结果需要后续完成 PRO 适配并锁定协议。

## 出错时提供什么

- 当时运行的完整命令。
- `git rev-parse HEAD`。
- `runs/reports/` 与相关 `runs/logs/` 文件。
- 数据准备失败时附任务名、demo 和帧索引。
- 显存/训练失败时附 GPU 数量和 `environment.json`。

不用发送密码、访问令牌或个人账号文件。代码修复通过本仓库分支和提交同步。

## 本版不能当成已完成的实验

本地只做代码和非 GPU 检查，尚未运行真实 π0.5 权重、MuJoCo 重放和训练。
脚本存在是工程实现完成的证据，不是实验通过的证据；优先完成小检查，再投入长训练。
